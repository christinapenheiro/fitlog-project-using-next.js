# 🏋️ FitLog — Workout Library

**FitLog** is a modern, responsive workout library built with Next.js. It helps users explore exercises, view detailed workout information, save exercises to their personal list, and add workouts to their daily training plan.

The project focuses on a clean dark-themed interface, responsive design, dynamic routing, API-based data fetching, and reusable React components.

## 🚀 Technologies Used

* **Next.js** — React framework for building the application
* **React** — Component-based UI development
* **TypeScript** — Type-safe JavaScript development
* **Tailwind CSS** — Responsive and utility-first styling
* **DaisyUI** — UI components and styling utilities
* **Next.js Image** — Optimized image handling
* **REST API** — Fetching workout and exercise data
* **Vercel** — Deployment and hosting

## ✨ Key Features

* 🏋️ **Workout Library** — Browse a collection of exercises with useful workout information.
* 🔎 **Exercise Details** — View detailed information including equipment, difficulty, sets, reps, duration, calories, rating, muscle groups, and instructions.
* 💾 **Save Workouts** — Save exercises to a personal saved list for quick access.
* 📋 **Daily Workout Plan** — Add exercises to a personal workout plan and manage the selected exercises.
* 🗑️ **Remove Workouts** — Easily remove exercises from saved lists or workout plans.
* ⭐ **Workout Ratings** — View exercise ratings to help understand the quality/popularity of each workout.
* 📱 **Responsive Design** — Designed to work across desktop, tablet, and mobile screen sizes.
* 🔗 **Dynamic Workout Routes** — Each exercise has its own dynamic URL using Next.js dynamic routing.
* ❌ **404 Handling** — Invalid workout routes and unavailable exercises are handled with a custom Not Found page.
* ⚡ **API Data Fetching** — Workout information is fetched dynamically from an external API.
* 🎨 **Dark Fitness UI** — A minimal, bold interface designed around a dark gym-inspired aesthetic.


## 🌐 Data Source

FitLog retrieves exercise information from an external REST API and uses the returned data to populate the workout library and individual workout detail pages.

## 📱 Responsive Experience

The interface is designed with responsive layouts so that the workout library, navigation, workout details, saved items, and daily plans remain usable on different screen sizes.

## 🎯 Project Goal

The goal of FitLog is to provide a simple and focused workout library where users can discover exercises, inspect their details, and organize workouts into personal plans.
